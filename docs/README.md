## 推荐阅读顺序

体验项目先读项目 README；需要开发或对接时，再读架构和 API。更换模型先看配置说明，启动失败先看运行手册。界面上的模板版和自由画布版同时保留，效果对照见 README 的真实视频样片表格。

## 验证边界

- 真实 NASA 视频已验证上传、ASR/OCR、分析、证据检索、DeepSeek 分镜、确认渲染及 MinIO 下载；自由画布对照复用同一解析结果。
- 四小时循环视频已验证上传完整性；本地预处理发现无效音频尾段，不能称为四小时完整解析通过。
- 模拟模型回归、合成演示、真实视频单样本分别记录，不合并为大规模效果结论。
- 模型调用、下载链接与字体环境会影响复现结果。已有文件哈希用于识别对应公开样片，不保证其他机器重新生成后逐字节相同。

## 维护约定

接口以 Java Controller 和 Python `creator/app.py` 为准；字段与校验以 `creator/models.py`、`creator/canvas_models.py` 及 Java 回调校验为准。更改这些约束时，同步 API 或渲染文档；更改模型和运行配置时，同步 `.env.example` 与运行说明。

文档只使用占位凭据。真实 `.env`、Cookie、服务日志、SQLite 状态和原始测试媒体留在本机。`docs/` 默认被忽略，公开文档需要明确加入 Git；不要整目录上传本地笔记和运行文件。
